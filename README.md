# AI 전문가 반복 퀴즈

노경섭 교수님 인공지능(AI)전문가 강의자료 1~23강을 복습하는 한국어 학습 도구입니다.

## 웹사이트

[AI 전문가 반복 퀴즈 열기](https://jungjae0821.github.io/ai-expert-quiz/)

GitHub Pages에서 공개 웹사이트로 제공됩니다. `main` 브랜치 루트를 배포하며, 학습 기록은 접속한 브라우저에 저장됩니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 여세요. 설치, API 키, 인터넷 연결 없이 사용할 수 있습니다.

클라우드 개발 환경에서는 다음과 같이 정적 서버로 확인할 수 있습니다.

```sh
python3 -m http.server 8000
```

서버가 실행되는 환경의 8000번 포트 미리보기를 여세요.

## 학습 범위와 기능

- 23개 강의, 원본 슬라이드 411장
- 객관식 148문항과 슬라이드별 서술형 310문항, 총 458문항
- 강의 선택, 검색, 무작위 출제, 모의시험, 오답·미학습·북마크·복습일 필터
- 문제별 정답 해설, 원문 텍스트와 슬라이드 이미지
- 브라우저 저장, 이어풀기, JSON 학습 기록 백업·복원

표지·목차·커리큘럼·빈 끝장을 제외한 310장에 서술형을 연결했습니다. 서술형은 참고 답안과 비교해 직접 채점합니다. 객관식만으로 모든 세부 내용을 복습하는 것은 아닙니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 그림까지 포함한 실행 가능한 단일 HTML |
| `questions.json` | 문제, 강의 텍스트, 출처, 보충 설명, 슬라이드별 범위 |
| `lecture-text.txt` | 전체 슬라이드의 추출 텍스트 |

## Codex Cloud에서 이어가기

이 저장소를 클라우드 환경에 연결한 후 아래처럼 요청할 수 있습니다.

> questions.json을 읽고 1~23강에서 객관식 20문제를 한 문제씩 내줘. 내 답을 받은 뒤 정답과 해설을 알려주고, 이번 대화에서 틀린 문제를 모아 다시 출제해줘.

범위를 정하려면 '13강 지표 계산 위주', '7~9강 자연어 처리', '서술형으로' 등을 덧붙이세요. JSON에는 정답도 들어 있으므로 채팅형 출제 시 사용자가 답하기 전에 정답을 노출하지 않도록 요청하세요.

## 검증과 제한

Microsoft Edge에서 연습 채점, 서술형 직접 채점, 모의시험, 새로고침 이어풀기, 원본 그림, 강의별 무작위 출제, 필터, 백업 다운로드·복원, 잘못된 백업 거부를 확인했습니다. 모바일 너비 390px에서도 가로 넘침이 없었습니다.

ROC·DQN·LDA 등 원문의 주요 혼동은 보충 설명으로 구분했습니다. 강의의 모든 사실을 독립 검증한 것은 아닙니다. 자격시험 운영, 회사별 성능, 제품·규제·산업 현황은 자료 시점의 설명입니다. 공식 기출문제가 아닙니다.

학습 기록은 기기·브라우저·사이트 주소에 따라 다를 수 있으므로 이동 전에 백업하세요. 기존 오프라인 HTML에서 저장한 기록은 백업한 뒤 웹사이트에서 불러올 수 있습니다. 강의자료에 대한 별도의 재배포 라이선스를 부여하지 않습니다.
